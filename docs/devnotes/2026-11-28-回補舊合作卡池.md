# 2026-11-28　1.3.0 回補 2022-10～2023-08 的合作卡池

## 改了什麼
- `scraper/backfill.js`：
  - `buildItems` 多收「日期早於活動清單第一筆、有合作角色表、沒被用掉」的合作公告，記成 `unlogged: true, tag: 'collab'`。
  - 新增 `collabEventName`：轉蛋名稱是「…祭」時，從標題【】取作品名，寫成「祭×作品」。
  - `parsed` 多存 `title`。
- `scraper/pool-parse.js`：
  - `planOne` 的 unlogged 分支只給本家。
  - `planCollab` 的卡池名稱：活動名稱是「…祭×作品」、轉蛋段落名稱是「…祭」時，用作品名。
- 測試 +3（134 個），新檔 `tests/backfill.test.js`。

## 為什麼
- 1.2.0 名冊拆分後，舊的 ★6 合作角色要靠回補補回；活動清單最早 2023-08-26，舊公告對不到活動。
- 使用者指出輝夜姬、地獄樂兩篇是「合作混本家限定」的卡池。

## 怎麼用
- Actions → 抓取轉蛋公告 → Run workflow，勾「歷史卡池回補」，起始日填 2022-10-01。

## 已知限制
- 清單開始之後的合作公告仍要對到活動才收（避免名稱不同時重複建卡池）。
- 舊活動不在活動清單裡，行事曆看不到；只補卡池與名冊。
- 同一作品兩篇公告（鏈鋸人 2022-10-27、11-02）會各跑一次；第二次名單相同，沒有變動。
